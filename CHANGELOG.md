# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-10-22

### Added

- Native-fetch Ollama and OpenAI-compatible streaming providers.
- Typed provider errors, timeout handling, rate-limit retries, and one-provider fallback.
- CLI commands for prompt execution, configuration, and audited shell watch mode.
- JSONL activity logs with credential redaction and size-based rotation.
- Unit tests and a Node.js 20/22 CI workflow.
